# Design Skill Set & Aesthetics

## Core Design Principles
Transitioning from a simple, personal aesthetic (sharyap.com) to a premium, tech-focused, and dynamic SaaS interface (InnoTech-Hub).

## Typography
- **Primary Font**: Manrope (for sans-serif, clean UI readability).
- **Display Font**: Playfair Display (for elegant, bold headings).
- **Monospace**: Used for telemetry data and developer-focused UI elements.

## Color Palette & Theming
- **Dark/Modern Theme**: Deep backgrounds (`bg-background`) with high-contrast text (`text-foreground`).
- **Gradients**: "Gradient Racing" (vibrant tech colors like primary red/orange to cyan/blue) for text highlights and borders.
- **Glassmorphism**: Extensive use of `backdrop-blur`, semi-transparent backgrounds (`glass`, `glass-strong`), and soft borders to create depth.

## Required CSS & UI Skills
1. **Tailwind CSS Mastery**: Proficiency in utility-first styling, grid/flexbox layouts, and responsive design.
2. **Micro-interactions & Animations**: 
   - Hover effects (scale, translate, glowing borders).
   - Infinite scrolling/marquee elements.
   - Pulse animations for active statuses (e.g., "SYSTEM ONLINE").
3. **Component Design**: Building reusable UI components (telemetry cards, event cards, feature grids).
4. **Icons & Assets**: Implementation of scalable SVG icons (Lucide Icons) and optimized webp/jpeg images.
