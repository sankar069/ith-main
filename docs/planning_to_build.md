# Planning to Build

## Overview
The goal is to replace the static, portfolio-style website design (previously seen on sharyap.com) with a dynamic, scalable SaaS and event ecosystem modeled after InnoTech-Hub.

## Phased Roadmap

### Phase 1: Foundation & Landing Page
- Set up Vite + React project.
- Implement the design system (Tailwind CSS, Glassmorphism UI, typography: Manrope & Playfair Display).
- Build the core landing page sections:
  - Hero section with live telemetry dashboard.
  - About Us & Mission.
  - Why We Started (Comparison section).

### Phase 2: Event Platform Integration
- Build the Event Discovery page.
- Integrate Auth (Login / Sign Up) for students.
- Develop the Event Registration & Payment/Ticketing flow.

### Phase 3: Student Growth Dashboard
- Build personalized user profiles.
- Implement tracking for: Registered events, Attended events, Certificates earned, and Skills gained.
- Develop the project submission portal.

### Phase 4: AI & Advanced SaaS Features
- Integrate AI Tooling: Event recommendations, AI idea generator, and Resume analyzer.
- Automate certificate generation upon project submission and review.
- Build analytics dashboards for college clubs and event organizers.
